# My Routine

Mobile-first skincare memory app that remembers what a user owns, what they use, how their skin reacts, and helps them decide what to use or buy next.

## Product promise

- Know what I own
- Know what I use
- Remember how my skin reacts
- Help me decide what to use or buy next

## MVP scope

1. **My Products** — lightweight skincare cabinet
2. **Today Routine** — AM / PM routine and daily use
3. **Skin Diary** — fast skin-state check-ins and history
4. **Should I use / buy this?** — contextual product decisions based on the user's skin, products, routine, and recent history

## v0.1 non-goals

- Fashion
- Makeup
- Social/community feed
- Marketplace
- Medical diagnosis
- AI skin scoring
- Complex product-photo recognition as a launch dependency

## Product principles

- Mobile-first
- Personal context over generic recommendations
- Memory over one-off answers
- Prefer **Replace** over automatically adding more products
- Avoid fake precision scores
- Keep daily interactions fast and lightweight

## Planned stack

- React Native
- Expo (stable SDK line)
- TypeScript

Backend, authentication, persistence, and AI architecture will be decided as part of the Foundation milestone before implementation.
